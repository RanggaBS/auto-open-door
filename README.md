# Auto Open Door

[![Mod Showcase](https://img.youtube.com/vi/EAphN1FG3WI/maxresdefault.jpg)](https://youtu.be/EAphN1FG3WI)

A lightweight mod for Bully: Anniversary Edition / Scholarship Edition / PS2 that allows doors to open automatically when the player is nearby, mimicking built-in NPC behavior for a more seamless gameplay experience.
